Текст карусели

Первая строка попадёт на обложку. Отделяй слайды пустой строкой. Внутри слайда первая строка станет заголовком.

Ключевую фразу в заголовке выделяй так: [[нужные слова]]. Обложка и финал оформляются отдельно. Для сравнения и чек-листа разделяй пункты переносами строк.

Фото целиком на обложке, без фильтров и изменений лица. Текст размещается отдельно от фотографии.

Серия постов

Впиши темы по одной на строку и скопируй задание в ChatGPT. Ответ целиком вставь во второе поле. Каждый пост откроется в редакторе.

Сгенерировать прямо в студии

Для владельца сайта после настройки OpenAI API на сервере.

Между постами поставь строку из трёх дефисов. Подпись начинай с новой строки со слова «Подпись:».

База знаний Notion

Выбери конкретную заметку в своей базе. Загрузи её по ссылке после подключения или вставь фрагмент вручную. Материал будет добавлен в задание для ChatGPT и в генерацию внутри студии.

Подключить чтение из Notion

Сайту нужен отдельный доступ только на чтение. Инструкция по настройке. Подключение Notion в ChatGPT не передаёт доступ этому сайту.

Импорт по ссылке требует серверной настройки. Ручной ввод доступен сразу.

Черновик источника сохраняется только на этом устройстве. При генерации выбранный материал передаётся OpenAI. Полный текст источника не попадает в изображения или ZIP.

Очередь выпусков

Выбери готовые посты и расставь время. Архив содержит слайды, подписи, расписание и серверный модуль. Публикация начнётся после его настройки на твоём сервере.

Как подключить автопубликацию

Внутри архива есть инструкция SETUP.txt. Понадобятся профессиональный аккаунт Instagram, токен Meta с правом публикации и сервер с HTTPS-доступом к изображениям. Планировщик запускается отдельно от браузера.
